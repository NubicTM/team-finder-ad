# TeamFinder — платформа для поиска команды проектов

**TeamFinder** — это веб-приложение, созданное для помощи разработчикам в поиске единомышленников и команд для совместной работы над IT-проектами. Платформа позволяет создавать проекты, управлять участниками, отмечать необходимые навыки и находить подходящие проекты через систему фильтров.

## 🚀 Основные функции

- **Управление проектами**: создание, редактирование, просмотр и поиск проектов.
- **Система участников**: возможность присоединиться к проекту в качестве участника.
- **Избранное**: авторизованные пользователи могут сохранять понравившиеся проекты.
- **Навыки**: гибкая система тегов для описания необходимых компетенций в проектах и у пользователей.
- **Фильтрация**: поиск проектов по навыкам, поиск пользователей по различным критериям.
- **Аутентификация**: регистрация, вход, управление профилем и смена пароля.
- **Администрирование**: полный доступ к управлению через встроенную админ-панель Django.

## 🛠 Стек технологий

- **Backend**: Python 3.10, Django 5.2
- **База данных**: PostgreSQL 14 (или SQLite для локальной разработки)
- **Frontend**: HTML5, CSS3, JavaScript
- **Среда выполнения**: Docker, Docker Compose
- **Дополнительно**: python-decouple, Pillow, psycopg2-binary

## 📋 Требования

- Python 3.10 или выше
- Docker и Docker Compose (рекомендуется)
- PostgreSQL 14 (если не используется Docker)
- Git
